# 🔍🛡️ URLSpectra

### Web Threat & Phishing Analysis System

URLSpectra is a cybersecurity web application that analyzes URLs for suspicious characteristics and provides a risk assessment.

## 🚀 Features

- URL format validation
- HTTPS analysis
- IP-based URL detection
- Suspicious keyword detection
- URL shortener detection
- Subdomain analysis
- Suspicious domain and TLD detection
- Suspicious file extension detection
- Query parameter analysis
- Special-character analysis
- Risk score calculation
- Risk classification
- Possible attack intent detection
- Security recommendations
- Analysis timestamp
- Simple web interface
- Clear/reset analysis option

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
